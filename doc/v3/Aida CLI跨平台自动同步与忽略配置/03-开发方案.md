## 3. 设计分层

### A. 本期必须完成

- 在 A-01、A-03、A-05、A-06 确认后，实现 macOS/Windows 自动同步、Intel Mac 发布、Session/目录忽略及所有上传入口的一致过滤。

### B. 代码事实触发的必要保障

- 在 A-02 确认后，实现跨平台上传锁；F-03 表明现有非 Linux 锁为空操作，缺少它会违反 R-02 的单次上传语义。
- 对 ignore 配置读取错误采取阻止上传策略；这是为满足 R-03/R-04 的隐私预期所需的必要保障。

### C. 后续增强

- 忽略规则导入/导出。
- 按规则记录被跳过的 Session 数量和原因。
- 不来自已发现 Session 的任意目录浏览器。

## 4. 变更边界

- 修改范围：`daemon/` 的命令路由、自动同步、各平台监督器/锁、Session 扫描和选择器、自更新目标映射、Makefile 发布构建与相关测试。
- 不修改范围：`api/`、`web/`、数据库迁移、上传 HTTP 契约、Session 解析和 Token 统计。
- 新增资源：仅本机 ignore 配置文件；依赖 A-03 确认。

## 7. 开发顺序与停止条件

1. 完成 P-01 至 P-04 并确认 A-01、A-02、A-03、A-05、A-06。
2. 先实现 ignore 配置、匹配和统一扫描过滤的单元测试。
3. 实现 `aida ignore` 交互入口及现有选择器复用。
4. 实现跨平台锁与平台调度 tick；保持 Linux 行为不变。
5. 补 Intel Mac 构建、发布和自更新映射。
6. 在真实三平台验证后发布。

若原型表明需要新增服务端接口、修改上传协议或改变 Session 父子归组口径，立即停止并返回需求/架构评审。若 P-04 无法复现，不能仅因单条反馈修改更新重启逻辑。
