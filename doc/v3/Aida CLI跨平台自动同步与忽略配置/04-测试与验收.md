## 4. 回归范围

- Linux systemd 与无 systemd 的独立后台自动同步。
- `aida upload`、`upload --all`、`upload --team` 的现有上传结果与退出码。
- Claude Code、Codex 的 Session 发现、索引、父子分组和增量上传。
- 已有 macOS arm64、Windows amd64、Linux amd64 的构建和自更新校验。

## 5. 真实链路验收

1. 准备一台 Intel Mac、一台 Apple Silicon Mac（优先反馈的 M5）、一台 Windows 用户环境，以及现有 Linux 环境；每台均以普通用户安装 CLI。
2. 使用隔离测试账号和可验证的本地 Session fixture；不使用生产用户令牌或生产 Session 内容。
3. 分别启用自动同步、观察调度器状态、让时间到达或触发等价 tick，再核对上传日志和服务端测试数据。
4. 在每台设备分别忽略一个 Session、一个目录及其子目录；核对手动和自动两类入口均无目标 Session 上传。
5. 保存系统任务状态、CLI 状态、上传日志、忽略配置权限、发布文件 SHA256 作为验收证据。

## 6. 发布门禁

- `linux/amd64`、`darwin/arm64`、`darwin/amd64`、`windows/amd64` 发布产物和 `SHA256SUMS.txt` 完整；
- 无未确认的 Codex 组忽略语义进入发布。
