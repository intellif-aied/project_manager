## 3. 人工确认的表达原则

- 按工作主题组织，不按交付状态组织标题；
- 测试服验证和生产发布必须独立表达；
- 用户界面使用“报告、日报、周报”，不使用“报表”；
- 保留`Report Agent/Report MCP/Report Context/Skill/Agent/MCP`，不机械翻译；
- “通知深链”必须写成“点击通知直接打开对应报告”；
- 组件名、错误码、端口、账号、hash、路径和命令不进入日报；
- 准备工作、讨论和纯轨迹可以从Brief排除；
- 最终日报由人工Review事实、状态、覆盖、简洁和自然度。
