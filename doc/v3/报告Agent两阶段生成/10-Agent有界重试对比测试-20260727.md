## 7. 策略判断

当前有界重试策略可以作为正式实现保留：

1. Brief最多允许2次无效纠正，即最多提交3次；
2. Result最多允许1次无效纠正，即最多提交2次；
3. 服务端一次返回全部可识别违规；
4. 计数按run持久化并原子递增；
5. 超限返回不可继续重试的明确错误码。

但不应增加“日报成功后再生成多份择优”的盲重试。下一阶段质量优化应落在Brief的语义约束或离线GT评分上，重点处理：概括范围、事实覆盖、低读者价值诊断、长报告压缩。否则增加调用次数只会放大模型随机性。
