### 生产主机时间同步

排查发现Aida生产服务主机时间超前，导致本地签发Token的iat早于模型网关时间，引发启动阶段401认证失败。评估后选择最小风险方案：启用systemd-timesyncd并配置内网NTP源，完成约91秒时间校正，确认容器无需重启即继承系统时间。目前生产主机已与NTP源同步。但模型网关与Aida主机仍未使用同一时间源，残留约27秒偏差，不能认定报告401已彻底修复。后续需评估将模型网关接入同一NTP源或统一时间基准。

### Token iat临时兼容方案

在时间同步无法彻底解决跨系统时间偏差的情况下，实施了临时兼容措施：将本地创建Token的iat回拨1小时，exp仍为真实当前时间起24小时。测试环境验证通过后发布生产API镜像。测试环境会话运行无401，Langfuse确认模型网关认证通过。生产API容器已正常启动。此方案为临时兼容措施，主流程是否应本地创建B Token需后续单独收敛。
