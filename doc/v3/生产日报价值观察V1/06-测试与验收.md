# 生产日报价值观察 V1：测试与验收

> 文档状态：已确认
> 日期：2026-07-28

## 1. 核心用例

| 用例 | 场景 | 可观察结果 |
|---|---|---|
| T-01 | 成功/失败个人日报 Run | 仅成功 Run 产生唯一 Snapshot；失败阶段可统计 |
| T-02 | AI 自动 saved 后无操作 | 只记 Observed Unchanged，不记 Confirmed Direct Use |
| T-03 | G=U 与 G≠U 的明确保存/提交 | Outcome 绑定正确 Run，直接使用和修改区间正确 |
| T-04 | G1→Save U1→G2 | G1/U1 和 G2 独立保留，历史不被重置 |
| T-04A | G1→Save U1→G2 后观察 | 当前用户日按 G2 分类：当前正文仍等于 G2 时记 Observed Unchanged，否则记无明确结果；G1/U1 只在时间线，不重复进入分母 |
| T-05 | 生成后删除 | 删除事件保留，Snapshot/此前 Outcome 不丢失 |
| T-06 | Summary 保持、修改、删除、缩短 | Summary Outcome 与长度变化正确 |
| T-07 | 中文、Markdown、空内容和长日报 | Diff 比例稳定，空分母为 `not_applicable` |
| T-08 | 主题新增、删除和改名 | 只输出结构变化信号，不伪造语义结论 |
| T-09 | 同日 AI/手写日报与多 Run | 覆盖、成功、重新生成分母正确 |
| T-10 | admin/非 admin | 仅 admin 可访问页面、正文详情和导出 |
| T-11 | 历史缺 Draft/Outcome | 显示“历史未采集”，不使用 `edited` 补算 |
| T-12 | 下游报告引用个人日报 | Downstream Reuse 口径正确 |
| T-13 | 14/30 日趋势与导出 | 趋势按同一 observed_at 复算；导出包含筛选、Hash 和相同指标，不依赖服务端快照库 |

## 2. 回归范围

- 个人日报生成、保存、提交、删除和重新生成；
- 其他五类报告；
- 普通 Agent；
- Report MCP 身份、来源和写回权限；
- 管理员路由与现有 AI 管理菜单。

## 3. 发布门禁

- D-01～D-06 对应测试通过；
- 新成功 Run 的 Snapshot 覆盖率为 100%；
- 多 Run 和删除场景不丢证据；
- 所有比例分子分母可复算；
- 非管理员无法访问；
- 生产请求链路没有 Reviewer 调用；
- 普通用户和其他报告无回归。
