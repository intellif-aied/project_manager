# 生产日报价值观察 V1

> 日期：2026-07-28
> 状态：需求与架构已确认，可开发
> 范围：生产环境默认 Report Agent 生成的 `personal_daily`

## 目的

为管理员提供按日查看 AI 日报实际使用价值的内部页面，证明 AI 是否稳定生成日报、减少用户撰写和修改工作，并为后续链路优化提供生产信号。

V1 不评价测试服候选方案，不决定版本是否上线。普通用户无新增入口或操作。

## 产品形态

管理员进入“生产日报价值观察”，选择 `report_date` 后查看：

- 当天个人日报总数、AI/手写日报数和 AI 覆盖率；
- Report Run 成功率、失败阶段、耗时和重新生成；
- 用户确认直接使用、Observed Unchanged 和修改程度；
- Generated Draft 保留率、用户新增比例；
- “工作总结”保持、修改、缩短和删除；
- 主题变化、生成后删除和下游采用；
- 用户级 Generated Draft 与用户稿对比；
- 近 14/30 日趋势和可复制汇报摘要。

## V1 边界

- 只处理生产 `personal_daily`；
- 只向管理员开放；
- 生产生成请求不调用 Reviewer；
- 不做模型排行榜、员工排名、自动发布或自动切流；
- 不回填无法恢复的历史 Generated Draft 和用户事件；
- 测试服固定数据集、Variant 配对和 Codex 评测属于“日报生成方案评测 V2”。
