# 日报生成方案评测 V2：架构设计

> 文档状态：已确认
> 日期：2026-07-28

## 1. 依赖边界

V2 复用“生产日报价值观察 V1”建立的 Generation Snapshot、Variant Manifest 和确定性文本差异能力，在测试服运行。V2 不依赖生产页面，也不读取生产数据库。

## 2. 目标架构

```text
固定 Dataset + 基线/候选 Variant
  → 在测试服顺序运行现有 Report 链路
  → 保存实际 Source / Digest / Context / Brief / Final / Metrics
  → 导出 Evaluation Bundle
  → 确定性检查
  → Codex + gpt-5.6-sol 单结果与匿名配对 Review
  → Gold Review
  → Scorecard + fixed/regressed + First Bad Stage
  → Evaluation Conclusion
```

## 3. 公平比较

端到端共同边界始终是 Source Evidence Snapshot 到 Final。Variant 内阶段可以不同：

- 无 Brief Variant 的 Brief 指标为 `not_applicable`；
- 不同 Digest 实现分别保存实际 Artifact；
- 只有契约可比的同名阶段并列比较；
- 阶段不同不改变 Final 的统一 Rubric；
- 同时改变多个变量时只评价整体 Variant。

## 4. 可选阶段评测

- Digest：Evidence 覆盖、状态/环境保真、噪声、确定性结构和耗时；
- Brief：Fact 引用/排除守恒、Deliverable `fact_refs`、归并、状态/环境和校验重试；
- Final：事实、状态、环境、归并、压缩、泄漏、重复、可读性和 Directly Usable；
- 不存在或不可比阶段明确为 `not_applicable`。

## 5. Evaluation Bundle

Bundle 绑定 Dataset、Variant、Rubric、Case 清单和所有输入 Hash。每个 Run 包含实际 Variant Manifest、Source Evidence、存在的阶段 Artifact、Generated Draft 和运行指标。

任一回归 Case 缺失、Hash 不一致或必需 Artifact 不完整时，不生成版本优劣结论。

## 6. 执行边界

- 内部脚本运行现有 Report 链路，不建设通用 DAG；
- Codex Skill 只读冻结 Bundle，不连接数据库；
- Reviewer 不进入生成请求；
- AI 与 Gold Review 分开保存；
- 结论不触发发布、切流或代码修改。
