# 日报生成方案评测 V2：测试与验收

> 文档状态：已确认
> 日期：2026-07-28

## 1. 核心用例

| 用例 | 场景 | 可观察结果 |
|---|---|---|
| T-01 | 还原 Variant | Manifest 唯一且 Hash 稳定 |
| T-02 | 相同 Dataset 跑 2～3 Variant | Case、Source Hash、重复和超时口径一致 |
| T-03 | 有 Brief / 无 Brief | 端到端统一比较，Brief 指标正确或 `not_applicable` |
| T-04 | Digest/Brief/Final 首次出错 | First Bad Stage 正确，级联不重复计数 |
| T-05 | pass/minor/unacceptable | Directly Usable 和聚合正确 |
| T-06 | 基线失败、候选修复及反向回归 | fixed/regressed 与配对 win/tie/loss 正确 |
| T-07 | 缺 Case、Artifact 或 Hash 不一致 | 停止结论并报告缺失，不补造数据 |
| T-08 | AI unacceptable、低置信度和回归 | 全部进入 Gold Review |
| T-09 | 匿名配对 | Reviewer 输入不暴露 Variant、模型和方案名 |
| T-10 | 同一 Bundle 重复运行 | 输出 Schema 稳定，证据引用可回放 |

## 2. 真实链路验收

1. 在完整回归 Dataset 上运行基线和候选；
2. 生成确定性检查和 AI Review；
3. 完成必需 Gold Review；
4. 输出 Directly Usable、错误类型、First Bad Stage、fixed/regressed 和性能；
5. 输出“改善证据成立 / 不成立 / 证据不足”。

## 3. 完成条件

- Dataset、Variant、Rubric 和 Bundle 均版本化；
- 所有回归 Case 已执行；
- AI 和 Gold 结果分开；
- 新增 unacceptable 回归有明确 Gold 结论；
- 没有生产调用、页面变化或自动发布行为。
