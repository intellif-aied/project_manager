# 日报生成方案评测 V2：开发方案

> 文档状态：V1 完成后实施
> 日期：2026-07-28

## 1. 前置条件

- V1 的 Generation Snapshot、Variant Manifest 和确定性 Diff 已可用；
- 测试服可按固定 Source Evidence 回放个人日报；
- V2 Dataset、Rubric 和 Bundle Schema 已冻结版本。

## 2. 实现任务

| 编号 | 任务 | 完成条件 |
|---|---|---|
| E-01 | 定义 Dataset、Variant、Rubric 和 Evaluation Bundle Schema | Hash 可校验，阶段允许 `not_applicable` |
| E-02 | 实现固定 Case 的 2～3 Variant 顺序执行器 | 相同输入、重复次数、超时和任务口径 |
| E-03 | 实现 Source、Artifact、Final 和指标导出 | 每个 Run 可完整回放 |
| E-04 | 实现确定性检查和 Scorecard 聚合 | 覆盖、错误、性能和 fixed/regressed 可复算 |
| E-05 | 创建仓库级 `$daily-report-eval` Skill | 完整 Bundle 生成 Schema 合法结果，缺失时停止 |
| E-06 | 实现匿名配对 AI Review 和 Gold Review 文件流程 | Reviewer 版本与输入输出 Hash 完整 |
| E-07 | 建立首版 10～20 Case Dataset | Baseline、标签、授权、Manifest 和 Hash 完整 |
| E-08 | 生成首份基线/候选版本评测报告 | 输出三态结论并交还优化会话 |

## 3. 开发顺序

1. E-01～E-03：先完成可重复执行和证据导出；
2. E-04～E-06：完成确定性与 AI/Gold Review；
3. E-07：契约稳定后选择并冻结 Dataset；
4. E-08：执行首轮真实 Variant 比较。

## 4. 不改范围

- 不开发测试评审后台页面；
- 不新增 Agent、MCP 或生成工作流；
- 不在线调用 Reviewer；
- 不修改生产价值观察页面；
- 不自动发布或选择 Variant。
