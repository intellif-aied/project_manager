## 3. 开发顺序

1. E-09～E-11：先修正证据冻结、Baseline 和 Runtime 接口；
2. E-12～E-13：完成形态统计与评审结论修正；
3. 回归 E-01～E-06 的 Bundle、匿名评审与 Scorecard 能力；
4. E-07：契约稳定后选择并冻结 Dataset；
5. E-08：执行首轮真实 Variant 比较。

## 4. 不改范围

- 不开发测试评审后台页面；
- 不新增 Agent、MCP 或生成工作流；
- 不在线调用 Reviewer；
- 不修改生产价值观察页面；
- 不自动发布或选择 Variant。
- 不在生产开启评测 Source/Artifact 接口；
- 不把手写日报全文作为 GT。
