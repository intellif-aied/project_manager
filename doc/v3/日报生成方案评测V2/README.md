> 日期：2026-07-28
> 状态：工程实现与五用户日真实链路验收已完成；正式回归 Dataset 与人工 Gold 待建设
> 环境：测试服

## 目的

其他开发会话完成一个候选 Generation Variant 后，V2 使用相同固定数据集运行基线和候选方案，通过确定性检查、Codex AI Review 和 Gold Review，给出本次优化是否有质量证据的结论。

V2 服务 Report 链路优化，不决定是否上线，不处理生产日报日常看板。

## V2 边界

- 一次只比较 2～3 个 Generation Variant；
- 端到端结论基于相同 Source Evidence 配对运行；
- Digest、Context、Brief 等阶段评测可选，缺失阶段为 `not_applicable`；
- 模型只是 Variant 配置，结论归属完整方案；
- 不做通用平台、在线 Judge、排行榜、自动发布或切流；
- 不建设生产管理员页面。
- 生产手写日报只作为聚合 Pattern Baseline，不作为 GT；
- 生产默认关闭评测证据接口，CLI 不直连数据库。
