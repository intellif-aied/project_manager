# 日报生成方案评测 V2：固定数据集

> 文档状态：已确认
> 日期：2026-07-28

## 1. V2 Dataset

首版建立 10～20 个 Evaluation Case，覆盖：

- 短、中、长 Session；
- 单 Session 与多 Session；
- 多主题和跨 Session 归并；
- 测试/生产状态混合；
- 高噪声、内部标识和敏感信息；
- 空信息、易遗漏和易过度压缩。

每个 Case 包含 `case_id`、报告任务、Source Evidence Snapshot、Evidence Baseline、标签、来源、用途授权和 Hash。

## 2. 样本来源

- 本机具有代表性的 Codex Session；
- 测试服已有可完整回放的 Source Evidence；
- 经明确授权后导入测试服的生产来源 Session。

生产来源样本进入测试服后只作为冻结测试 Evidence，不连接生产实时数据。选择具体 Case 在 V1 数据基础和 V2 Bundle 契约完成后进行。

## 3. 版本规则

- Dataset 发布后不原地修改；
- Case、Source 或 Baseline 变化时生成新版本；
- 开发集用于定位问题，不单独证明候选更优；
- 回归集每次必须全部执行；
- 经 Gold Review 确认的新失败类型进入下一 Dataset 版本；
- V2 不建设 Holdout。

## 4. 形成流程

1. 只读盘点并形成 20～30 个匿名候选；
2. 验证可从 Digest 前 Source Evidence 完整回放；
3. 按标签选择 10～20 个 Case；
4. 人工标注 Evidence Baseline；
5. 生成 Dataset Manifest 和 Hash；
6. 发布 Dataset V1，后续只新增版本。
