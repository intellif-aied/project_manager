## 核心目标

1. 默认 Report Agent 的模型额度统一由环境专用账号承担；
2. Report MCP 运行时始终使用当前 AIDA 用户身份访问业务数据；
3. Aida 前端暂时屏蔽“我的 Skill”“我的 MCP”，后端能力和已有数据保留。

默认 Report Agent 固定使用模型 `deepseek-v4-flash`。

本方案只允许修改默认报告 Agent 的模型额度归属、Report MCP 运行身份绑定和对应前端资产入口。任何不能直接追溯到三个核心目标的改动均不进入本方案。
