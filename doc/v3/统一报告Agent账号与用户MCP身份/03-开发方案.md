## 3. 设计分层

### A. 本期必须完成

- 环境默认 Report Agent、Report MCP Credential 容器和 Session 使用 `100866/10086` 专用账号，默认模型为 `deepseek-v4-flash`，并启用共享模型额度；
- 确认报告 Session 不选择用户个人模型 Token override；
- 保留当前用户 `AIDA_REPORT_MCP_AUTH` Credential Override；
- 前端屏蔽个人 Skill/MCP 管理入口和旧直达页面；
- 增加对应定向测试。

### B. 必要保障

- 断言系统账号 Token 不进入 Report MCP Credential；
- 断言不同用户的报告 run 使用不同用户 Credential；
- 断言普通 Agent 和其他 AI 资产功能不受影响。

### C. 后续增强

无。本方案不创建隐含后续任务。

## 4. 变更边界

- 修改范围：默认报告 Agent 资产配置/发布逻辑、必要的报告 Session 请求字段、AI 资产前端展示与路由、定向测试；
- 不修改范围：报告来源、Digest、Context、写回、组织权限、其他 Agent、定时任务、个人资产后端接口和数据；
- 新增资源：无新增表、migration、服务或协议。

## 9. 实施结果（2026-07-27）

- 默认 Report Agent 的创建、修复和 `default` 运行解析已切换到基础专用平台客户端；
- 默认报告新增独立配置 `MANAGED_AGENT_REPORT_MODEL_ID`，默认值为 `deepseek-v4-flash`，不改变普通 Agent 的 `MANAGED_AGENT_DEFAULT_MODEL_ID`；
- 默认报告 Run 写入内部 `system_report_account` 标记，提交器仅对该链路使用专用账号创建 Credential 和 Session；自定义报告 Agent 继续使用原用户平台身份；
- Report MCP Credential 的值仍为当前 AIDA 用户 Token；
- 前端已隐藏个人 Skill/MCP 页签、指标、创建入口，旧创建地址重定向到 AI 资产首页；Agent 编辑器的资源选择能力保留；
- 无数据库 migration、无第三方平台代码改动。
