## 已确认边界

- 使用现有个人 Token 登录，不新增团队账号、团队 Token 或设备凭据；
- 服务端在每次团队上传请求中读取登录用户最新团队，不在 CLI 保存或上送 `team_id`；
- 团队 CLI 上传沿用现有 Token 过期可用规则；
- 个人在“我的 Token”配置自己的绝对目录；
- Prepare 在上传内容前按目录确认同步资格；唯一既有 Session 延续原 owner，新 Session 按目录确定 owner；
- 曾由一个账号代传全组的存量 Session，可按已配置目录执行一次性 Session 级归属拆分，之后由 Team 模式在原 Session 上续传；
- 同一 Session 不拆 Chunk、不因登录账号或目录 owner 变化而中途换人；
- 未配置目录不上传，通过 `aida log` 汇总；
- 普通个人上传、个人自动同步和既有下游统计保持不变。
