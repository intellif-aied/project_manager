## 3. 设计分层

### A. 本期必须完成

- 个人同步目录持久化、本人 CRUD 和我的 Token 页面入口；
- Prepare 团队目录路由、直接个人 owner 和首次归属固化；
- Generation 团队写入授权；
- CLI 手动团队上传、自动同步团队模式、未配置目录日志；
- 既有个人 Session 的团队模式续传与一次性历史归属拆分；
- 个人模式兼容、下游个人统计和日报来源验收。

### B. 代码事实触发的必要保障

- 上传状态增加模式命名空间并迁移 v1，防止个人与团队 cursor 串用；
- 未配置目录不触发自动同步每分钟重试；
- 团队模式禁止 legacy batch fallback，保证未匹配内容不会绕过 Prepare；
- 同一团队 Session 的目录删除时停止后续同步；目录 owner 变化时既有 Session 保持原 owner，新 Session 使用新 owner；
- 当前团队存在多条同 `agent_type + session_ref` 时拒绝上传，防止系统自动选择或合并；
- Chunk、Finalize、Status、Abort、Abort 清理使用同一团队 Generation 权限条件。

### C. 后续增强

无。
