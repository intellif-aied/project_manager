# 日报邮件通知配置与通讯录导入说明

> 日期：2026-08-06
> 状态：开发完成，待环境配置与真实链路验收

## 1. 腾讯企业邮箱配置

只需要配置邮箱地址、SMTP 授权码和发送时间：

```text
REPORT_EMAIL_ADDRESS=<腾讯企业群发邮箱完整地址>
REPORT_EMAIL_PASSWORD=<SMTP 授权码>
REPORT_EMAIL_TIME_OF_DAY=08:00
```

发送时间按北京时间解释，默认 `08:00`。系统固定使用腾讯企业邮箱 `smtp.exmail.qq.com:465`、implicit TLS，邮箱地址同时作为 SMTP 账号和发件地址。邮箱地址与授权码都为空时功能关闭；只填写其中一项时 API 拒绝启动。授权码不得写入仓库、数据库或日志。

需要在保留邮箱地址和授权码的同时临时关闭邮件时，增加运行开关：

```text
REPORT_EMAIL_ENABLED=false
```

权限开通后可改为 `true`，或删除该开关恢复按三项邮箱配置自动启用。

## 2. 通讯录匹配预览

CSV 表头必须为 `display_name,email`。默认命令只读取并输出匹配结果，不写数据库：

```bash
cd api
go run ./cmd/report-email-recipient-import \
  -csv '<企业邮箱通讯录.csv>' \
  -database-url '<目标数据库 URL>'
```

输出状态：

- `matched`：唯一精确匹配，可申请导入；
- `not_found`：Aida 无同名用户；
- `ambiguous`：Aida 存在重名；
- `invalid_email`：邮箱格式错误；
- `email_conflict`：邮箱已属于其他用户或 CSV 内冲突。

## 3. 显式导入

人工确认 dry-run 清单后，添加 `-apply` 才会写入 `report_email_recipients`。对测试服或生产执行 apply 属于数据库写入，必须单独获得用户授权。本开发任务不执行导入。
