# 日报邮件通知配置与通讯录导入说明

> 日期：2026-08-06
> 状态：开发完成，待环境配置与真实链路验收

## 1. 功能开关与 SMTP

功能默认关闭。启用时必须完整配置：

```text
REPORT_EMAIL_ENABLED=true
REPORT_EMAIL_TIMEZONE=Asia/Shanghai
REPORT_EMAIL_TIME_OF_DAY=08:00
REPORT_EMAIL_SMTP_HOST=<群发邮箱 SMTP 主机>
REPORT_EMAIL_SMTP_PORT=587
REPORT_EMAIL_SMTP_USERNAME=<群发邮箱账号>
REPORT_EMAIL_SMTP_PASSWORD=<群发邮箱密码或授权码>
REPORT_EMAIL_SMTP_FROM=<发件地址>
REPORT_EMAIL_SMTP_FROM_NAME=Aida 日报
REPORT_EMAIL_SMTP_TLS_MODE=starttls
```

`REPORT_EMAIL_SMTP_TLS_MODE` 只允许 `starttls` 或 `implicit`。密码不得写入仓库、数据库或日志。

## 2. 通讯录匹配预览

CSV 表头必须为 `display_name,email`。默认命令只读取并输出匹配结果，不写数据库：

```bash
cd api
go run ./cmd/report-email-recipient-import \
  -csv '<企业邮箱通讯录.csv>' \
  -database-url '<目标数据库 URL>'
```

输出状态：

- `matched`：唯一精确匹配，可申请导入；
- `not_found`：Aida 无同名用户；
- `ambiguous`：Aida 存在重名；
- `invalid_email`：邮箱格式错误；
- `email_conflict`：邮箱已属于其他用户或 CSV 内冲突。

## 3. 显式导入

人工确认 dry-run 清单后，添加 `-apply` 才会写入 `report_email_recipients`。对测试服或生产执行 apply 属于数据库写入，必须单独获得用户授权。本开发任务不执行导入。
