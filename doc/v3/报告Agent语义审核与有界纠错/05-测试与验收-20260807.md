- 产品验收从 REQ-01 至 REQ-05 派生；
- 先验证 Compiler 和状态收敛，再调用真实 Reviewer；

- 固定相同 Facts、Memory Snapshot 和候选 Brief 对比结果。

## 5. 真实链路验收

## 6. 发布门禁

- T-01 至 T-07、A-T01 至 A-T05 全部通过；
- 后端完整测试通过；
- 固定异常样本不再复现；
- Reviewer 故障不影响报告成功率；
- 无个人 Agent 和非个人日报回归；
- 未决架构项为 0。
