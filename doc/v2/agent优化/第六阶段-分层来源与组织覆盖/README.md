# 第六阶段：通用 Report Context V1

> 状态：需求已定稿；主体架构已收敛，三项验证只阻塞对应实现与发布  
> 更新日期：2026-07-20

第六阶段的唯一产品目标是：六类报告由平台确定性准备并冻结基础事实，默认 Agent 读取一次完整 Report Context 后生成报告，不再自由编排基础取数。

## 当前准入状态

以下决策验证完成前，只暂停对应实现，不阻塞六类 Context 构建和冻结能力开发：

- 同一 Run 的容量提醒确认协议；
- Report MCP 凭据与当前 Run 的强绑定方式；
- 完整 Report Context 的 Aida 平台保护上限。

其余设计以复用现有 `reportcontext.Service`、`report_run_contexts`、`ai_runs` 和六类现有报告数据为基线，不预设新增表、迁移、服务或通用证据系统。

- 02–04 不得追加产品规则；

- 需求、架构或代码事实发生变化时，按“需求 → 事实 → 架构 → 开发 → 测试”顺序同步。
