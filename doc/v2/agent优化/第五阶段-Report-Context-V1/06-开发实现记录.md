## 2. Context 内容

Context V1 保存：

- run_id、report_type、period、target；
- Digest content_mode；
- 已由 reportsource 完整校验的冻结 Digest 全量 payload；
- 数据库侧 hash 和 bytes。

不执行第二次摘要、Top-K、重要性排序、事实数量限制或正文审查。
