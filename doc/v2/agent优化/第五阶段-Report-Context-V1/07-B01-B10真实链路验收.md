## 5. 测试中发现并修复的问题

首个联调 Run 的动态运行消息仍残留旧 `get_sessions` 指令。该 Run 不计入验收。修复内容：

- `buildReportRunMessage` 改为只传 run_id 调用 `get_report_context`；
- 增加断言，selection Context 消息不得包含“调用 get_sessions”；
- 重新构建 API 后，B01-B10 实际调用均为 1 / 0 / 1。

该问题证明运行协议必须同时核对默认 Agent instructions、start prompt、动态 session message 和 Skill，不能只修改其中一层。
