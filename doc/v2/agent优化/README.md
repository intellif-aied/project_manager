# 报告 Agent Session Digest 优化

> 日期：2026-07-16
> 适用范围：个人日报、个人周报生成中的 Session 来源压缩与结果质量优化

本目录按阶段维护 Session Digest 方案，避免已上线的容量治理与后续结果质量优化混在同一组文档中。

## 统一边界

- 第二阶段基于第一阶段继续演进，不回滚服务端 Digest，也不重新让报告 Agent 完整读取原始 Session。
- Session 上传协议、来源权限、Token 统计口径和报告写回语义继续以既有产品基准为准。
- 第一阶段文档记录已上线的 `session-digest/v1` 设计、实现和验证。
- 第二阶段文档只讨论 `session-digest/v2` 的结果证据模型、真实 Session 评测、开发与发布。
- 各阶段内部发生冲突时，以该阶段 README 中声明的权威顺序为准。
