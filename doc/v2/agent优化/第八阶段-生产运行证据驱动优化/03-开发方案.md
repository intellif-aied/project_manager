## 7. 开发顺序与停止条件

```text
验证身份关联与 usage
  -> 分层采样
  -> 重建执行时间线
  -> 确认根因和基线
  -> 更新架构决策与代码落点
  -> 实现纯函数 Report Projection
  -> 最大样本覆盖与性能测试
  -> 确认 Digest 队列指标不劣化
  -> 同输入同模型对照
  -> 全链路回归
  -> 进入发布评审
```

出现以下任一情况立即停止代码开发：根因只能靠猜测、需要新增 LLM/Job/队列/表、需要改变产品规则、无法取得相同输入对照、任一结果无法按固定规则解释为“保留结果首段”或“排除过程噪声”、生产证据与文档冲突。
