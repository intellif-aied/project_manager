> 需求基线：[01-需求文档.md](01-需求文档.md)

## 1. 测试原则

- 本轮 Projection 修复只比较同一冻结 Digest 与 Projection，不调用 Agent，不以模型输出判断 Projection；
- 完整性和瘦身分别验收：有效 Work Unit、业务结果、验证、失败、风险和未解决事项不得丢失；代码、命令、路径、纯 Git、传输包装和内部过程噪声应减少；
- Context 字节数和压缩率只作为瘦身指标，不能覆盖事实完整性失败；
- 质量结论必须逐条核对事实覆盖，不能只依赖字数；
- 未确定的代码改动不预设内部实现测试。
