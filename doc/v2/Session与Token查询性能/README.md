# Session 与 Token 存储查询优化

本目录是该专项的唯一开发依据。

## 文档结构

1. [需求说明](./01-需求说明.md)：交付目标、产品契约和边界。
2. [架构设计](./02-架构设计.md)：目标架构、数据模型、数据流、时序和异常处理。
3. [开发方案](./03-开发方案.md)：实施顺序、代码边界、交付物、完成定义和进度。
4. [测试验收](./04-测试验收.md)：功能、性能、数据一致性和恢复验收。
5. [发布清单](./05-发布清单.md)：完整功能范围、发布单元、数据任务、回滚和当前发布判定。

## 使用规则

- 产品和技术结论只写入对应文档，不保留讨论或事故过程。
- 开发进度只以《开发方案》为准，测试结果只以《测试验收》为准。
- 只有《发布清单》的完整功能门禁全部通过，才能宣布专项完成。
