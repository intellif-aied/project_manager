## 4. 删除方式

旧表没有通过手工 SQL 删除。生产使用提交 `2f35019` 中的受控 `compact-session-events finalize`：

- 强制 state=`swapped`；
- 强制固定表身份；
- 强制新表无 Payload；
- 强制旧表存在；
- 强制回滚触发器已移除；
- 强制精确 `--confirm-drop`；
- 使用 5 秒锁等待上限和 30 秒语句上限；
- 同一事务删除旧表、清理函数、重命名约束/索引并更新 `finalized`。
