### 4.2 Token 和成本

- 固定样本每账号两天分别为 120、100 Token，总计 220。
- 6 账号合计 1320 Token；全量重复上传后仍为 1320，成本仍为 `USD 0.005625000000`。
- gpt-5.4 样本按 Input、Cache Read、Output 分项计量；两天 CNY 成本分别为 `0.0034334445`、`0.00294052425`，使用汇率快照 `6.7989`。
- 跨日按事件活动日期归属，不按 Session 启动或上传日期归属。
- 累计值回退、多个模型、未知模型未计价、价格快照、时区边界、pending/ready 由真实数据库集成测试覆盖。
- 权限实测：`t03` 只能看本组 `t06`，`t04` 只能看本组 `t09`，`t02` 可看两个小组；PM 和工程师访问管理统计返回 403。

### 4.3 报告来源和 MCP

- 不传日期可返回候选切片；日期与跨日切片相交时返回完整切片。
- 同一 Session 的增量切片独立返回，Summary 使用各自内容。
- 直接 MCP 使用选择快照时只返回所选 marker 切片，未选切片未混入；选择后新增内容不会进入既有快照。
- 组织越权验证通过。
- **修复前失败：** `POST /api/v1/ai-assets/report-agents/default/runs` 传 UUID 切片曾返回：

```text
HTTP 400
selected_session_slice_keys must use session_id:YYYY-MM-DD
```

修复后，运行入口校验 UUID，并通过现有 reportsource 服务创建显式选择快照。Agent 与 MCP 使用 `report_source_selection_id` 读取快照，不再直接解释切片键。定向回归返回 HTTP 200，MCP 仅返回所选切片，最终报告保存成功。
