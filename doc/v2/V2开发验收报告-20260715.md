## 2. 来源参数验收结论

当前正式路径是 `report_source_selection_id`：

1. 前端提交 `selected_session_sources`，只包含用户可见的 session_ref、agent_type 和活动时间范围。
2. 服务端创建不可变 Report Source Selection，固化 Session、Source、Generation、Content Projection Revision、cursor 和 content epoch。
3. 本地 report run 绑定 selection 后，Agent/MCP 通过 `report_source_selection_id + run_id + report_type + period` 读取固定快照。
4. 后续上传、generation 切换或内容清除不会让已启动报告换来源；epoch 不一致时读取失败。

旧的 `selected_session_slice_keys` 是迁移兼容参数。它按 `session_id:YYYY-MM-DD` 表达历史自然日切片，无法稳定表达跨天连续活动，也无法锁定后续 generation/cursor，因此被新 selection 快照替代。当前仍保留旧参数是为了兼容历史自定义 Agent/旧调用，不是前端新产品路径；新路径和旧参数同时提交会明确返回 `AMBIGUOUS_REPORT_SOURCE`。
