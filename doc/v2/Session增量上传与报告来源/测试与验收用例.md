# Session 增量上传与报告来源测试与验收用例

## 1. 测试规则

- 使用 14.157 测试环境，不发布生产。
- 使用 6 个真实测试账号，覆盖四类角色和至少 2 个小组。
- 自动化测试通过真实接口模拟行为，禁止前端自动化 E2E。
- 前端由产品负责人人工验收，未确认前不得写“前端通过”。
- MCP 和默认 Skill 必须真实更新到测试环境后再测。
- 同时执行直接 MCP 调用和真实 Agent 六类报告。

## 2. 上传与切片

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| 首次上传 | 上传一个从未上传的真实 Session | 形成 1 个切片，内容覆盖本次已有内容 |
| 后续上传 | 在同一 Session 增加内容后再次上传 | 只新增 1 个切片，只包含新增内容 |
| 连续上传 | 同一 Session 连续新增并上传两次 | 每次各增加 1 个切片 |
| 无新增 | 不增加内容再次上传 | 不增加切片 |
| 重复操作 | 重复上传同一段新增内容 | 不产生重复切片 |
| 上传失败 | 模拟接口失败 | 不形成可选择切片 |
| 跨天内容 | 一次上传包含跨天新增内容 | 仍只形成 1 个切片 |
| 切片摘要 | 查看同一 Session 的多个切片 | 每个 Summary 只描述自身内容 |
| 日期筛选 | 筛选范围与跨日切片相交 | 返回完整切片，不裁剪内容 |

## 3. 手动个人报告

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| 单切片 | 选择一个切片生成个人日报 | 只使用该切片 Session 内容 |
| 多切片 | 选择同一 Session 多个切片 | 使用全部已选切片 |
| 多 Session | 选择多个 Session 的切片 | 使用全部已选来源 |
| 排除未选 | 同时存在已选和未选切片 | 未选切片不进入 Session 来源 |
| 生成后新增 | 报告开始后继续上传 | 新内容不进入本次已选切片 |
| 个人周报 | 选择切片生成个人周报 | 来源与选择一致并成功保存 |

## 4. 组织报告

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| 小组日报 | 两个小组准备成员个人日报后生成 | 分别汇总本组已保存个人日报 |
| 小组周报 | 两个小组准备成员个人周报后生成 | 分别汇总本组已保存个人周报 |
| 部门日报 | 准备所管小组日报后生成 | 汇总所管小组已保存日报 |
| 部门周报 | 准备所管小组周报后生成 | 汇总所管小组已保存周报 |
| 角色权限 | 四类角色分别调用相关接口 | 只能访问各自授权范围 |

## 5. Token 与成本

1. 上传前记录 6 个账号的 Token、成本、模型和日期归属。
2. 完成首次、增量、无新增、重复、失败和跨天测试。
3. 再次读取相同统计接口。
4. 同一原始使用记录不得重复；既有 Token、成本和日期归属不得改变。
5. 切片列表 Token 只用于识别，不替代 Token 页面统计结果。

## 6. MCP 与 Skill

1. 将修改后的 MCP 和默认 Skill 真实更新到 14.157 测试环境。
2. 直接调用测试环境 MCP，验证手动个人报告所选切片来源。
3. 直接调用测试环境 MCP，验证小组和部门报告下级报告来源。
4. 使用测试环境实际生效的 MCP/Skill 运行真实 Agent。
5. 分别生成个人日报、个人周报、小组日报、小组周报、部门日报、部门周报。
6. 核对来源、权限、运行记录、最终正文和保存结果。
7. 本地文件、Mock、临时提示词和未发布资源均不得计为通过。

## 7. 冻结项回归

- 定时任务现有行为不受影响。
- 前端现有 UI 不受影响，等待人工确认。
- MCP 授权、凭证、工具定义、owner/version 和绑定方式不受影响。
- Token、成本和日期归属口径不受影响。

## 8. 停止条件

任一用例失败、来源越界、UI发生未确认改动、MCP配置被改变、Token对账不一致或六类报告失败时，立即停止，不继续后续阶段，不发布生产。
