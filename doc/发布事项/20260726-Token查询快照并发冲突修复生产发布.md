## 4. 变更内容

- Rollup V2 查询快照事务由 `SERIALIZABLE` 改为 `REPEATABLE READ`，仍保持单事务 MVCC 一致视图和原子提交。
- `40001` 保留三次完整事务重试，退避为 50ms、150ms、350ms，并增加不超过 25% 的抖动。
- 重试耗尽后固定返回 `503 + TOKEN_SNAPSHOT_BUSY`，不再向用户暴露 PostgreSQL 原始错误。
- 快照 Token、15 分钟有效期、Rollup 统计口径及前端调用顺序均未改变。
