## 8. 停止条件

出现以下任一情况立即停止并回退：

- 生产专用账号、Token 归属或模型权限无法确认；
- API/Web 新容器健康检查失败或持续重启；
- 默认 Agent owner、模型、SkillRef、MCP 用户身份任一不符合目标；
- 真实报告运行出现身份串用、额度归属错误、Skill 加载错误或报告无法回写；
- 当前生产配置或镜像无法可靠恢复。
