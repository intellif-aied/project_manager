## 功能范围

1. Session source 进入 ready 后，按实际 Session owner 和上海自然日汇总；同一用户来自多台主机的上传会进入同一份日报。
2. 当该用户当日所有已就绪 source 连续静默 120 秒后，调度系统 Report Agent 自动生成个人日报。
3. 后续有新 source 就绪时重新等待静默窗口，并仅刷新此前由上传自动生成且未被用户编辑、保存或提交的日报。
4. 用户已经手写日报、已有非本功能生成的日报，或自动日报已被编辑、保存、提交时，不执行自动生成或刷新。
5. `--team` 上传仍按每条 Session 的实际 owner 分组，不按执行上传命令的机器或操作者归属。
6. 多副本调度使用数据库租约和 source 指纹保证幂等；每次生成使用冻结的 source 切片列表。
7. 运行时开关默认关闭，可通过管理员 API 动态开启或关闭，无需重启服务；每次变更写入审计表。

## 待人工验收

1. 使用测试用户在一台或多台机器执行 `aida upload session`。
2. 确认 source 就绪并静默约 2 分钟后自动出现当日个人日报。
