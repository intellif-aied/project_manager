## 3. 功能与安全边界

1. 只处理开关开启后进入 ready 的当日 Session source，静默窗口为 120 秒。
2. 同一用户来自多台主机的 source 汇总到同一日报；团队上传按 Session 实际 owner 分组。
3. 后续 source 可刷新本功能生成且尚未被用户编辑、保存操作或提交的日报。
4. 已有手写日报、其他触发来源日报、已编辑或已提交日报均不覆盖。
5. 调度使用数据库租约、source 指纹和冻结切片列表，避免多副本重复生成。
6. 管理员可动态开关，无需重启；配置变更写入审计事件。
