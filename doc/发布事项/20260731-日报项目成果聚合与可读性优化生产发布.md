## 3. 用户可感知改动

1. Git、目录、文件、测试、构建、合并和部署信息只用于判断工作是否属于同一项目，不再直接作为日报事项。
2. 同一项目的方案、实现、修复和验证优先合并，避免按 Session 或操作步骤拆成多条。
3. 系统默认个人日报的 Report Brief 只保留项目成果，不根据局部 Session 推导“尚未合并”“尚未发布”“不建议上线”等外部状态。
4. 工作概览使用普通读者能理解的中文表达，不直接复制内部架构名、方法名或新造术语。
5. 表达质量不足继续允许降级写回，不能扩大为用户生成失败。

兼容边界：个人自定义 Agent、周报、团队/部门报告、系统/个人 Agent 路由、MCP 鉴权、Session 选择和前端交互不变。
