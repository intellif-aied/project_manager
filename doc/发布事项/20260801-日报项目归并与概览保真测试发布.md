## 主要行为

1. 正常 Brief 可以只选择值得汇报的 Fact，服务端将其余 Fact 以内部 `not_selected` 自动归档；空日报仍需显式说明全部排除。
2. System Skill 先建立“项目或能力 → 模块、候选、实验、活动”两层关系，再创建 Workstream；同一命名对象下的评测、训练、调研和文档合并。
3. 固定项目名和专业术语保持原名；普通工作用自然中文描述，不把“调整弹窗点击后的跳转”包装为“通知深链”。
4. 概览保持 Markdown 有序列表，每个 Workstream 一项，每项最多两个高价值结果，具体指标和子结果留在正文。
5. 所有规则均为 System Report Skill 软约束；个人 Agent、周报、MCP Interface 和服务端成功门槛不变。
