## 3. 修复内容

- Linux 仍优先使用 systemd user service 管理自动同步。
- Docker 等缺少 systemd user manager 的环境，启动现有 `aida auto-sync daemon-run` 独立后台进程。
- 使用 PID 文件避免重复启动，并支持 `disable`、停止和重启。
- PID 文件采用原子写入和 `0600` 权限；停止时先发送 `SIGTERM`，超时后再强制结束。
- 不使用 cron 回退，避免容器内只有 `crontab` 命令但没有运行 cron daemon 时产生错误成功状态。
