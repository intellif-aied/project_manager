## 7. 验收期间发现并修复的问题

首次清理后上传验收发现 Digest V2 Reconciler 仍有一个未纳入 Session-first 的后台 Job 创建入口，产生 1 次与 Usage Activation 的反向锁序。

提交 `c35c93f`：

- Reconciler 收集候选后先按 Session ID 排序；
- 对所有 Session 依次加行锁；
- 之后才创建 Digest Revision 和 Processing Job；
- 新增真实 PostgreSQL 并发测试，确认 Reconciler 在 Session 锁之前不会创建 Revision。

该问题不是旧表删除造成，但属于本次生产上传验收的阻断项，因此当场 forward fix；未将首次验收误判为通过。
