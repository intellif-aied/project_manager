## 9. 止损与回退

### Digest

Digest 异常时：

```env
MANAGED_AGENT_REPORT_SESSION_READ_MODE=full
```

重启 API。只影响新建报告 run，已经冻结的 Digest run 按原契约完成或明确失败。不得启用 shadow 或临时账号灰度。

### API/Web

- Web 可恢复旧镜像标签；
- API 优先发布 forward fix；
- 迁移 `018` 是前向兼容迁移，不反向删除表、列、约束；
- 如果新客户端已经开始使用 abort/fork 新协议，不得直接回到不识别新状态的旧 API。

### Report Skill

将生产配置恢复为：

```env
MANAGED_AGENT_REPORT_SKILL_VERSION=1.0.3
```

保留本次新 Skill 资产，不覆盖、不删除历史版本。

### Aida CLI

- 在 `aida-latest.txt` 覆盖前可直接停止发布；
- 覆盖后可把发现开关暂时恢复为 `0.1.4`，阻止尚未升级的客户端继续升级；
- 已经安装 `0.1.5` 的客户端不会自动降级；
- 如需修复已升级用户，应发布更高版本 `0.1.6`，或明确通知人工重装旧版。
