## 8. 回滚与停止条件

本次无 migration 和数据改写，回滚只替换 API 镜像：

1. 恢复备份 `.env` 中的 `API_IMAGE_TAG`；
2. `docker compose pull api`；
3. `docker compose up -d --no-deps api`；
4. 验证容器镜像、`/health` 和 Session 上传。

注意：回退到 `4e9c28b` 会重新引入 Digest/Usage 死锁；回退到发布前 `77d9a42` 会重新引入本 P0 的完整已知问题。因此只有最终镜像自身造成更严重回归时才执行回退，回退后必须立即停止上传高峰并继续修复。

立即停止条件：Session Sync 持续 5xx、数据库新增死锁、cursor 不追平、CLI 成功但当天列表缺失、重复上传新增 Generation/事件或 Token/Fork 口径发生变化。
