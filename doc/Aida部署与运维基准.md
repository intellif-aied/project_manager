共同规则：

1. 部署前检查实际源码目录、分支、HEAD 和未提交修改。
2. 只部署本次发生变化的组件，不重启或发布无关组件。
3. 测试服与生产服的地址、凭据、镜像和 CLI 产物不得混用。
4. 构建和部署结果必须从实际服务地址复查，不能只检查本地文件。
5. 密码、JWT、MinIO 密钥和服务 Token 不写入 Git、文档或日志。
6. 已有工作区修改默认属于用户或其他协作者，不覆盖、不回退、不混入发布。
7. 部署文档只描述部署，不包含产品使用说明或功能测试流程。
