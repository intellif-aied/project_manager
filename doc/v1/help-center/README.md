# AIDA 用户指南与流程文档

本目录是 AIDA 面向业务用户的指南内容、角色流程、截图资产和维护规则的统一入口。范围只包含四个业务角色：工程师、团队负责人、产品经理、部门总监；管理员与 AI 管理模块不在本帮助中心范围内。

## 文档索引

- [四角色流程与权限矩阵](./四角色流程与权限矩阵.md)：按角色和模块说明可见范围、主要动作和权限边界。
- [帮助中心技术实现与维护](./帮助中心技术实现与维护.md)：说明前端架构、内容模型、路由匹配、版本维护和发布流程。
- [截图索引与验收记录](./截图索引与验收记录.md)：记录截图来源、隐私规则、页面覆盖和验收结果。

## 产品内入口

登录后，在以下页面顶部选择“使用指南”：

1. 快速开始：从 Token、客户端和 Session 上传到第一份 AI 日报。
2. AIDA 客户端 / Session 页面。
3. 工作台。
4. 需求看板及任务详情。
5. 日报。
6. 周报。

指南根据当前登录角色过滤文章与截图，同一份内容模型不复制成四套文档。管理员不会看到该入口。

## 内容真源

- 线上文章数据：`web/src/layouts/HelpCenter/helpCenterContent.ts`
- 指南交互：`web/src/layouts/HelpCenter/HelpCenter.tsx`
- 路由归类：`web/src/layouts/HelpCenter/helpCenterConfig.ts`
- 页面样式：`web/src/layouts/HelpCenter/HelpCenter.css`
- 截图资产：`web/public/help-center/screenshots/`，按 `v1/`、`v2/` 等界面版本维护

更新页面或权限时，应同时更新文章内容、角色矩阵、截图索引和对应截图，避免产品行为与帮助内容分叉。
