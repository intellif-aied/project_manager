# Aida 使用手册

平台地址：http://113.100.143.91:9180

先安装 Aida 客户端，登录并上传本机 Codex / Claude 会话，再到网页里查看工作台、日报和周报。

## 1. 安装 Aida 客户端

### macOS / Linux

```bash
curl -fsSL http://113.100.143.91:9180/statics-live/aida/install.sh | bash
```

如果安装后提示找不到 `aida`，重新打开终端，或执行安装结束时提示的 `source ~/.bashrc` / `source ~/.zshrc`。

### Windows PowerShell

```powershell
Invoke-RestMethod http://113.100.143.91:9180/statics-live/aida/install.ps1 | Invoke-Expression
```

安装后重新打开 PowerShell。

## 2. 登录 Aida 客户端

```bash
aida login
```
输入 你的登录 token

检查登录状态：

```bash
aida status
```

## 3. 上传本机会话

查看本机可上传的 Codex / Claude 会话：

```bash
aida upload
```

上传指定会话：

```bash
aida upload 1,3,5
```

上传全部会话：

```bash
aida upload --all
```

上传后，在网页「Token 用量」里可以看到对应 Session。

## 4. 日报怎么用 Agent 生成

进入网页「工作台」或「日报」：

1. 点击「填写日报」。
2. 选择日期。
3. 点击「AI 生成」。
4. 如果还没有默认报告 Agent，页面会提示创建，按提示创建默认 Agent 后再生成。
5. 个人日报可点 选择Session按钮 选择 Session 切片；不选则按日期自动取数。
6. 检查内容，必要时修改。
7. 点击保存。

## 5. 周报怎么用 Agent 生成

进入「周报」：

1. 点击「填写周报」。
2. 确认周期。
3. 点击「AI 生成」。
4. 如果还没有默认报告 Agent，页面会提示创建，按提示创建默认 Agent 后再生成。
5. 个人周报可选择 Session 切片；小组/部门周报不需要手动选择。
6. 检查内容并保存。

## 6. 定时报告任务怎么用

进入「AI 资产」-「定时任务」：

1. 点击「新建定时任务」。
2. 选择报告 Agent。
3. 设置报告类型、运行时间和模型 ID。
4. 保存后，系统会按时间自动生成报告。
5. 可在「运行历史」查看定时任务是否成功。

如果只想立刻生成一次日报/周报，直接在日报或周报弹窗里点「AI 生成」即可，不需要建定时任务。

## 7. 自定义 Skill 怎么调用 MCP

Aida Report MCP 是平台内置能力，默认报告 Agent 已自动绑定，不需要用户手动填写 MCP 地址或 token。

如果要写自己的报告 Skill，参考：`doc/Aida Report MCP 使用说明.md`。

## 8. 工作台怎么看

登录网页后先看「工作台」：

- 我的事项：需要你处理、关注或负责的需求和任务。
- 我的风险提示：逾期、依赖阻塞、依赖冲突等风险。

点击事项或风险，可以直接打开需求详情或任务详情。

## 9. 需求和任务怎么用

进入「需求看板」：

1. 用「我的事项 / 关注 / 负责 / 创建 / 全部」切换范围。
2. 点击需求查看详情。
3. 在需求详情里看负责人、任务拆解、验收标准、操作记录。
4. 点击任务查看任务详情。
5. 任务被阻塞时，查看「上游依赖」确认阻塞来源。

任务状态只有三种：

- 未开始
- 进行中
- 已完成

## 10. 常见问题

### 为什么网页里没有 Session？

先在本机执行：

```bash
aida upload --all
```

上传完成后再刷新「Token 用量」页面。

### 为什么 AI 生成日报/周报失败？

常见原因：

- 没有上传 Session。
- 没有默认报告 Agent。
- 模型 ID 或 Agent 配置异常。

可以到「AI 资产」的「运行历史」查看失败原因。

### 什么是默认报告 Agent？

默认报告 Agent 是日报/周报 AI 生成使用的 Agent。首次使用 AI 生成时，如果没有默认报告 Agent，页面会提示创建。

### 我只想手写日报可以吗？

可以。直接填写正文并保存，不一定要 AI 生成。
