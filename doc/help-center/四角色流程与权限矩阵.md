# 四角色流程与权限矩阵

## 1. 角色定义

| 角色 | 系统值 | 工作范围 | 报告范围 |
| --- | --- | --- | --- |
| 工程师 | `employee` | 本人创建、负责、参与或关注的需求与任务 | 个人日报、个人周报 |
| 团队负责人 | `team_leader` | 本人及所属团队范围 | 个人、小组成员、小组汇总日报周报 |
| 产品经理 | `pm` | 跨团队需求推进与本人事项 | 个人日报、个人周报 |
| 部门总监 | `director` | 部门范围及跨团队风险 | 个人、部门成员、部门汇总日报周报 |

管理员不纳入用户指南，也不显示指南入口。

## 2. 快速开始

四个角色共享同一条首次成功路径：复制个人 Token → 安装 AIDA 客户端 → `aida login` → `aida status` → `aida sessions` → `aida upload` → 从工作台打开个人日报 → 选择日报归属日期 → AI 生成 → 检查并保存。日报弹窗顶部的日期决定报告归属；打开 Session 选择抽屉后，其中的开始日期和结束日期仅用于筛选候选 Session。

完成标准是目标日期的日报已经保存并出现在“我的日报记录”，不是只完成客户端安装或 Session 上传。未手动选择 Session 时，报告 Agent 按目标日期查找相对应的记录；选择后只使用勾选的 Session 切片。

## 3. AIDA 客户端与 Session 上传

四个角色流程相同：

1. 按操作系统安装 AIDA 客户端。
2. 从右上角个人菜单选择“复制 Token”。
3. 执行 `aida login` 绑定当前 AIDA 地址与个人令牌。
4. 执行 `aida status` 核对登录身份。
5. 执行 `aida sessions` 查看最近 Session；可用 `--project` 按项目筛选。
6. 首次建议执行 `aida upload` 交互选择，确认后上传。
7. 回到 Session 页面检查记录；日报与周报的 Session 选择器会读取已上传记录。

安全边界：令牌不得出现在需求、日报、周报、聊天或截图中；Session 摘要可能包含终端命令、内部地址或凭据，上传前必须检查。

## 4. 工作台

### 通用流程

1. 查看“我的事项”，优先判断阶段、负责人、截止时间和风险。
2. 选择事项详情，下钻到需求抽屉或任务弹窗。
3. 查看“我的风险提示”，处理需求逾期、任务逾期、依赖阻塞和依赖冲突。
4. 在“报告处理”确认当天日报和本周周报状态。
5. 通过日报、周报入口进入完整历史记录。
6. 查看 Token 使用趋势；管理角色还可查看团队范围汇总。

### 角色差异

| 能力 | 工程师 | 团队负责人 | 产品经理 | 部门总监 |
| --- | :---: | :---: | :---: | :---: |
| 本人事项与风险 | 是 | 是 | 是 | 是 |
| 小组日报、周报处理 | 否 | 是 | 否 | 否 |
| 部门日报、周报处理 | 否 | 否 | 否 | 是 |
| 团队 Token 汇总 | 否 | 小组 | 否 | 部门 |

## 5. 需求看板

### 5.1 查找需求

1. 在“我的事项、关注、负责、创建、全部”之间切换范围；具体可见数据仍由后端权限决定。
2. 在阶段看板与需求列表之间切换。
3. 使用关键词、阶段、优先级和风险筛选。
4. 选择需求卡片打开需求详情。

### 5.2 创建需求

团队负责人、产品经理和部门总监可以看到“新建需求”；工程师不显示该入口。

创建时需要明确：标题、需求描述、负责人、参与团队、截止时间、优先级和验收标准。创建后继续拆分任务。

### 5.3 需求详情

详情抽屉保持单一滚动责任：抽屉外壳不滚动，任务、验收、动态在各自内容区滚动。

1. 顶部确认标题、阶段、优先级和主要操作。
2. 概览直接展示需求说明，不再把描述藏在独立标签中。
3. 有权限时快捷编辑截止时间、负责人和参与团队。
4. 在“任务”中拆分和推进执行项。
5. 在“验收”中核对完成条件。
6. 在“动态”中查看关键变更。
7. 标签栏右侧使用“关联 session”管理需求级工作记录。

### 5.4 任务与依赖

任务负责人更新状态与进度时，前端必须保持 `done`、`progress`、`completed_at` 一致；需求和任务更新携带 `base_version`，冲突时刷新后重新编辑。

依赖流程：选择当前任务 → 添加上游任务 → 核对阻塞关系与截止时间 → 上游完成后确认阻塞解除。依赖关系不是普通备注，错误依赖会直接进入风险统计。

### 5.5 权限边界

能打开需求不等于能修改全部字段。页面以接口返回的能力字段决定是否显示编辑、阶段修改、任务创建、依赖和验收操作；无权限时仍可阅读说明、任务、验收与动态。

## 6. 日报

### 6.1 个人日报

所有角色均可：按日期范围查看记录、折叠预览、展开全文、复制 Markdown、编辑历史记录和填写任意日期日报。

编辑流程：通过日历图标选择日期 → 填写正文 → 可选填写最多两行的明日计划 → 直接保存，或用 AI 生成 → 检查内容 → 保存。个人日报可按需选择 Session，但这不是 AI 生成的前置条件：未选择时由报告 Agent 按目标日期查找相对应的 Session；选择后仅使用已勾选的 Session 切片。

Session 选择只用于个人日报。列表默认每页 10 条，翻页保留已选记录；清空选择后恢复按日报日期取数。摘要可能包含敏感上下文，选择前应检查。个人日报和部门汇总日报弹窗均可通过日期旁的日历图标切换目标日期。

### 6.2 成员与汇总

| 视图 | 工程师 | 团队负责人 | 产品经理 | 部门总监 |
| --- | :---: | :---: | :---: | :---: |
| 个人日报 | 是 | 是 | 是 | 是 |
| 成员日报 | 否 | 小组成员 | 否 | 部门成员 |
| 汇总日报 | 否 | 小组汇总 | 否 | 部门汇总 |

成员日报用于晨会快速浏览：折叠状态读取成员、提交状态和一行预览；展开后查看完整 Markdown 或复制全文。小组、部门汇总由组织范围数据生成，不使用个人 Session 选择器。

## 7. 周报

个人周报按自然周管理。所有角色均可查看、展开、复制、编辑和补写自己的历史周报；生成前确认目标周，按需要选择日报或 Session 上下文。

| 视图 | 工程师 | 团队负责人 | 产品经理 | 部门总监 |
| --- | :---: | :---: | :---: | :---: |
| 个人周报 | 是 | 是 | 是 | 是 |
| 成员周报 | 否 | 小组成员 | 否 | 部门成员 |
| 汇总周报 | 否 | 小组汇总 | 否 | 部门汇总 |

成员周报适用于周会快速浏览；汇总周报应检查成果、风险、缺失成员和下周计划后再保存。

## 8. 角色主链路

### 工程师

AIDA 上传 Session → 工作台处理本人事项与阻塞 → 在需求中维护本人任务 → 填写个人日报 → 填写个人周报。

### 团队负责人

AIDA 上传 Session → 工作台处理本人和小组风险 → 创建或管理团队需求与任务 → 浏览成员日报并形成小组日报 → 浏览成员周报并形成小组周报。

### 产品经理

AIDA 上传 Session → 工作台关注跨团队交付 → 创建、拆解并推动跨团队需求 → 维护个人日报和周报。

### 部门总监

AIDA 上传 Session → 工作台查看部门风险和报告状态 → 从需求看板下钻跨团队问题 → 浏览部门成员日报并形成部门日报 → 浏览部门成员周报并形成部门周报。
