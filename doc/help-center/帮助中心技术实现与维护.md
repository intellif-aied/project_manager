# 帮助中心技术实现与维护

## 1. 设计原则

帮助中心采用“一个内容模型、按角色过滤、按当前页面进入”的方案，不维护四套重复文档。

- AIDA 客户端是第一个一级入口，优先解决 Session 上传这一前置流程。
- 工作台、需求、日报、周报按用户任务组织文章，不按代码目录组织。
- 当前路由决定默认模块；用户仍可在抽屉中浏览其他模块。
- 当前角色过滤文章、章节和截图。
- 正文优先：抽屉宽度为 `min(1040px, 100vw)`，左侧导航 184px，桌面端文章列表使用双列。
- 文章截图可点击预览原图。

## 2. 前端结构

```text
web/src/layouts/
  Header/
    Header.tsx                 顶部入口与管理员排除
  HelpCenter/
    HelpCenter.tsx             抽屉、搜索、文章、代码复制、截图预览
    HelpCenter.css             内容优先布局与响应式样式
    helpCenterConfig.ts        路由到帮助模块的映射
    helpCenterContent.ts       角色化文章数据

web/public/help-center/screenshots/v1/
  emp/                         工程师
  tl/                          团队负责人
  pm/                          产品经理
  dir/                         部门总监
```

## 3. 内容模型

`HelpArticle` 以模块、角色、路由、关键词和章节组成。文章与章节都可限定角色；截图还可再次限定角色，因此同一篇文章可以只向当前身份展示对应界面。

章节支持：段落、步骤、要点、提示、可复制命令和截图。AIDA 客户端命令块使用深色高对比样式，复制操作兼容安全上下文 Clipboard API 与旧浏览器回退。

## 4. 路由映射

| 路径 | 帮助模块 |
| --- | --- |
| `/sessions*` | AIDA 客户端 |
| `/dashboard` | 工作台 |
| `/requirements*`、`/tasks*` | 需求看板 |
| `/reports/daily*` | 日报 |
| `/reports/weekly*` | 周报 |

其他页面不显示使用指南。Header 在角色为 `admin` 时不创建入口。

## 5. 搜索与导航

搜索覆盖文章标题、摘要、关键词、章节正文、步骤、要点、提示和命令。输入只更新草稿，按 Enter 或选择搜索按钮后执行，清空输入立即恢复当前模块。

文章底部“前往对应页面”使用文章配置的路由导航，并关闭抽屉。打开新模块会清空搜索与文章选择，避免保留不相关状态。

## 6. 截图规范

1. 只通过真实登录账号和可见 UI 采集，不注入令牌。
2. 文件名只使用 ASCII，按角色目录与页面顺序命名。
3. 不截登录表单、Token、Cookie、localStorage、开发者工具或终端凭据。
4. Session 摘要可能包含内部地址、命令和密码；未经逐条检查不得采集 Session 列表截图。
5. 页面改版或角色权限变化时更新截图并升级目录版本，例如 `v2/`；旧版本保留到文章引用迁移完成。

## 7. 内容更新流程

1. 修改页面功能或权限。
2. 更新 `helpCenterContent.ts` 中相关步骤、角色和关键词。
3. 使用对应角色登录，走完受影响流程。
4. 更新截图资产和本目录截图索引。
5. 执行前端 lint、typecheck、test、build。
6. 检查所有图片请求成功，文章搜索与“前往对应页面”可用。
7. 发布时将代码和 `web/public/help-center/` 静态资产一起交付。

## 8. 为什么暂不做独立后台

当前帮助内容与前端路由、权限和页面版本强绑定，使用 TypeScript 内容源可以获得编译期校验、版本评审和同版本发布。内容规模明显增长、需要非研发人员频繁编辑、需要发布审批或多语言时，再将文章迁移到后端 CMS；迁移时保留现有 `HelpArticle` 契约作为 API DTO。

## 9. 回归要求

- 四个业务角色都能打开指南，并只看到自身可执行流程。
- AIDA 客户端始终是左侧第一个模块。
- 管理员看不到入口。
- `/tasks/*` 直接打开时仍归入需求指南。
- 搜索、返回、模块切换、代码复制、图片预览、页面跳转和遮罩关闭均可用。
- 桌面端正文有效宽度充分；小于 768px 时导航转为横向滚动且文章单列。
