# AIDA 平台访问与使用指引

## AIDA 是什么

AIDA 是面向研发协作的内部工作平台，用于集中管理工作台事项、需求与任务，以及个人和团队的日报、周报。

平台会结合已上传的 AIDA Session，辅助整理工作记录和生成报告，减少重复汇总工作。不同角色看到的数据范围和操作权限不同，请以登录后的实际页面为准。

## 访问平台

AIDA 使用 **AIHub 账号体系**。请使用本人已有的 AIHub 工号和密码登录，不需要单独注册 AIDA 账号。

如果无法登录，建议依次确认：

1. 使用的是本人 AIHub 工号和密码。
2. AIHub 账号当前可以正常使用。
3. 账号已经开通 AIDA 访问权限。

仍然无法登录时，请通过下方反馈入口提交问题，并附上发生时间和页面提示；不要提交密码或个人 Token。

## 第一次使用

登录后，建议先完成以下流程：

1. 打开页面右上角的 **使用指南**。
2. 从 **快速开始** 了解 Token、AIDA 客户端、Session 上传和生成第一份日报的完整流程。
3. 根据实际工作进入工作台、需求看板、日报或周报模块。
4. 遇到具体操作问题时，在使用指南中选择对应模块，或通过搜索查找操作、字段和常见问题。

站内使用指南会根据当前账号角色展示可执行的流程和权限说明。平台功能发生变化时，以站内指南为最新版本，本飞书文档只维护访问入口和基础说明。

## 数据与安全提醒

- 个人 Token 只用于本人客户端登录，不要发送到群聊、需求、日报、周报或反馈表单中。
- Session 可能包含工作上下文，上传和关联前请检查是否存在敏感信息。
- 不确定是否有权限执行某项操作时，以页面实际显示的按钮和权限提示为准。
